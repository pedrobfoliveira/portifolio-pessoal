Principais projetos

Simulação de Sistema de Delivery (iFood) em Java

Java

Projeto desenvolvido como parte da avaliação da disciplina de Programação Orientada a Objetos, com o objetivo de aplicar, na prática, os principais conceitos de POO utilizando a linguagem Java.

O sistema simula funcionalidades básicas de uma plataforma de delivery inspirada no iFood, modelando usuários, restaurantes, cardápios e pedidos.

Ver repositório

Projeto Slay the AED em C/C++

C/C++

Projeto desenvolvido em equipe como trabalho semestral da disciplina de Algoritmos e Estruturas de Dados (AED).

O jogo é inspirado no estilo do Slay the Spire, utilizando mecânicas de combate por turnos, cartas e progressão por fases, com foco principal na aplicação prática de estruturas de dados em linguagem C/C++.

Ver repositório

Posto de Gasolina em SQL

Oracle SQL

Projeto desenvolvido em grupo como trabalho semestral da disciplina de Banco de Dados, com foco em modelagem relacional, SQL e PL/SQL utilizando Oracle Database.

O sistema simula o funcionamento de um posto de combustíveis com loja de conveniência, abrangendo clientes, funcionários, produtos, vendas, estoque e regras de negócio.
