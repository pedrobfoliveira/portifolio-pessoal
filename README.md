# 🌐 Portfólio Pessoal — Pedro Boaventura Ferraz de Oliveira

Projeto desenvolvido com o objetivo de apresentar minha trajetória acadêmica, experiências, habilidades técnicas, cursos, participações em eventos e formas de contato em um site pessoal moderno, responsivo e visualmente organizado.

O portfólio foi construído utilizando **HTML** e **CSS**, com foco em uma interface limpa, agradável e em tons de azul, buscando transmitir de forma clara minha formação e minhas competências na área de tecnologia.

---

## 👨‍💻 Sobre o Projeto

Este site foi criado para funcionar como uma vitrine pessoal e profissional, reunindo em um só lugar informações importantes sobre minha formação em **Engenharia da Computação**, experiências acadêmicas, ferramentas que utilizo, cursos realizados e participações em eventos.

Além de servir como apresentação pessoal, o projeto também reforça conhecimentos em estruturação de páginas web, organização visual e estilização com CSS.

---

## 📌 Informações Apresentadas no Portfólio

O site contém as seguintes seções:

- **Apresentação pessoal**
- **Experiências**
- **Tecnologias e ferramentas**
- **Cursos complementares**
- **Participações em eventos**
- **Premiações**
- **Idiomas**
- **Contatos**

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido com:

- **HTML5**
- **CSS3**

Essas ferramentas foram utilizadas para estruturar o conteúdo, estilizar a interface e adicionar ícones visuais às tecnologias apresentadas no portfólio.

## ▶️ Como Visualizar o Projeto

**Pré-requisitos:**

Você só precisa de um navegador de internet.

**Execução:**

Para abrir o projeto localmente, basta clonar este repositório e abrir o arquivo index.html no navegador.

```bash
git clone https://github.com/pedrobfoliveira/NOME-DO-REPOSITORIO.git
```

Depois, entre na pasta do projeto e abra o arquivo principal.

Para abrir o projeto remotamente, basta entrar no site pedrobfoliveira.vercel.app
